# NBA Dashboard

This is a simple NBA dashboard project. It shows NBA players and stats using React.  
I am using this project to practice React, JavaScript, and Git/GitHub.

## How to run the project
1. Install dependencies:
   npm install

2. Start the development server:
    npm start
    
## Project folders
- **src/** – React components and pages  
- **public/** – public assets  
- **components/** - contains the charts and other components that will be used
- **data/** - contains all JSON files
- **package.json** – project info and dependencies
